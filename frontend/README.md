# Frontend README

React portfolio frontend built with Vite.

## 🚀 Setup

```bash
npm install
npm run dev
```

Frontend runs on `http://localhost:3000`

## 📂 Structure

- `src/pages/`: All portfolio pages
- `src/components/`: Reusable components
- `src/services/`: API client
- `src/styles/`: CSS files

## 🔗 Pages

- `/` - Home
- `/about` - About Me
- `/skills` - Skills
- `/experience` - Experience
- `/projects` - Projects
- `/contact` - Contact Form
- `/ai-assistant` - AI Chat Assistant

## 📦 Build

```bash
npm run build
npm run preview
```

## ⚙️ API Configuration

Backend endpoint: `http://localhost:8080/api`

Configure in `src/services/api.js`
